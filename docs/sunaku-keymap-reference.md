# Glorious Engrammer — quick reference (macOS build)

Cheat sheet for the trial keymap on the `sunaku` branch, built as
`firmware-archive/sunaku-glorious-engrammer-qwerty-macos-diff1.uf2`.

**Read this before trusting sunaku's own diagrams.** The PNG layer diagrams
in his repo (`README/*-layer-diagram.png`) are *committed static images*, not
generated — `rake` only converts them PNG→PDF. They therefore always show his
**Linux** defaults, and his keymap deliberately swaps Win/Ctrl on macOS. The
accurate rendering of what we actually build is
`keymap-drawer/glove80.svg` on the `sunaku` branch, generated by CI from
`config/glove80.keymap` itself.

## Home row mods

Tap for the letter, hold for the modifier. 500ms hold (`DIFFICULTY_LEVEL 1`).

| | pinky | ring | middle | index |
|---|---|---|---|---|
| **Left** | `A` → **Ctrl** | `S` → **Alt** | `D` → **⌘ Cmd** | `F` → **Shift** |
| **Right** | `;` → **Ctrl** | `L` → **Alt** | `K` → **⌘ Cmd** | `J` → **Shift** |

Note **Cmd is on the middle finger**, not the pinky. On Linux this would be
GACS (Win/Alt/Ctrl/Shift); on macOS he swaps Win↔Ctrl deliberately, so it
becomes Ctrl/Alt/Cmd/Shift. `MACOS_USE_GACS` would suppress that swap if the
Linux ordering is ever preferred.

`ENFORCE_BILATERAL` is on: a home row mod will not fire for a same-hand
tap, which cuts down misfires while typing normally.

## Thumb keys

Tap for the key, hold for the layer.

| Pos | Key | Hold → layer |
|---|---|---|
| 52 (LT1) | `Esc` | Function |
| 53 (LT2) | — | Lower |
| 54 (LT3) | `Page Up` | — |
| 55 (RT3) | scroll up | — |
| 56 (RT2) | `Insert` | Lower |
| 57 (RT1) | `Enter` | **System** |
| 69 (LT4) | `Backspace` | **Cursor** |
| 70 (LT5) | `Delete` | **Number** |
| 71 (LT6) | `Page Down` | — |
| 72 (RT6) | scroll down | — |
| 73 (RT5) | `Tab` | Mouse |
| 74 (RT4) | `Space` | **Symbol** |

Versus the stock layout: **Backspace (69) and Space (74) do not move.**
`Enter` moves to 57 (currently RShift) and `Tab` lands on 73 (where Enter is
now) — that pair is the main thing to re-learn.

## Combos

Two keys pressed together. Thumb positions are `T1`–`T6` per hand.

| Combo | Does |
|---|---|
| **T1+T4** | **⌘ Cmd+Tab app switcher** — then tap to cycle |
| T3+T6 | Alt+Tab menu — then tap to cycle |
| T2+T5 | Ctrl+Tab menu — then tap to cycle |
| T1+T5 | Shift (tap = sticky one-shot) |
| T4+T5 | CapsWord on/off |
| T2+T6 | CapsLock on/off |
| T1+T2 | sticky RAlt (AltGr) |
| T2+T3 | sticky Globe (macOS) |
| **T5+T6** | **Typing layer — enables key auto-repeat** |
| T1+T2+T3 | unlock all, return to base layer |
| C1R5+C2R6 | Gaming layer on/off |

Two of these matter a lot given earlier discussion:

- **T1+T4 is the Cmd+Tab switcher** originally wanted at the start of all
  this — hold-free, tap repeatedly to go back N apps. It needs no custom
  module and no Nix workaround; it is already in this keymap. Verified in
  `keymap-drawer/glove80.yaml` as `p: [52, 69] → &mod_tab_chord LGUI`.
  (On Linux the same combo is Alt+Tab; the OS setting swaps it.)
- **T5+T6 (Typing layer) enables key auto-repeat**, which is the likely
  answer to the Neovim `hjkl` problem — `J`/`K`/`L` are home row mods, so
  holding them normally sends a modifier instead of repeating. Worth testing
  whether this layer makes held-`j` scrolling work again. Not yet verified.

## Alpha layouts

Base is QWERTY. Others are reachable at runtime through the Magic layer, no
reflash needed:

| | |
|---|---|
| Magic + `=` | Enthium (his default) |
| Magic + `1` | Dvorak |
| Magic + `2` | Colemak |
| Magic + `3` | QWERTY |

## Settings changed from his defaults

Both live in the `#define` block near line 885 of `config/glove80.keymap`
on the `sunaku` branch. Keep tweaks confined there so they are easy to
re-apply when pulling a newer version of his keymap.

| Setting | His | Ours | Why |
|---|---|---|---|
| `OPERATING_SYSTEM` | `'L'` | `'M'` | he targets Linux |
| `DIFFICULTY_LEVEL` | `0` (150ms) | `1` (500ms) | most forgiving |

Other notable defaults left as-is: `ENABLE_MOUSE_KEYS` on,
`ENFORCE_BILATERAL` on, `SPACE_FORGIVENESS` / `THUMB_FORGIVENESS` /
`SHIFT_FORGIVENESS` off, `NATURAL_SCROLLING` off (worth revisiting if mouse
layer scrolling feels inverted).
